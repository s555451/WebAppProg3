Instructions: How to Make French Toast

  1. Whisk eggs, milk, and cinnamon in a shallow bowl.
    1. Use 2 fresh eggs per cup of milk.
    2. Add a pinch of nutmeg if desired.
  2. Dip slices of bread into the mixture until saturated.
  3. Cook on a hot, buttered skillet until golden brown.

Code Snippet: LinkedList

This snippet demonstrates a custom LinkedList class in Java, including double-linked node navigation and list operations.

Source link: UT Austin CS314 Code Examples - LinkedList

public class LinkedList<E> implements Iterable<E> {
    private DoubleListNode<E> head;
    private DoubleListNode<E> tail;
    private int size;

    public LinkedList() {
        head = new DoubleListNode<E>();
        tail = new DoubleListNode<E>();
        head.setNext(tail);
        tail.setPrev(head);
        size = 0;
    }

    public void addLast(E item) {
        DoubleListNode<E> newNode = new DoubleListNode<E>(item, tail.getPrev(), tail);
        tail.getPrev().setNext(newNode);
        tail.setPrev(newNode);
        size++;
    }
}
